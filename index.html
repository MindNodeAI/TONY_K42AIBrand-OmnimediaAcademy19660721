04 / TAKE THE METHOD WITH YOU

      
下載方法，保留人的判斷。


      

        

          STEP 01 / 取得 Skill
          
下載原創 Skill 壓縮包

          

            在單元卡片點擊「下載 Skill」，解壓縮後包含 SKILL.md、OpenAI Agent 設定與練習評量參考檔；可依您使用的 AI 平台匯入。
          

        


        

          STEP 02 / 啟動協作
          
上傳指令並貼上工作台提示詞

          

            在支援讀取附件的 AI 對話中提供 SKILL.md 與參考檔，再從上方工作台複製您的專屬提示詞貼入，即可展開結構化引導。
          

        


        

          STEP 03 / 完成與帶走
          
查核來源、匯出全案簡報

          

            核對事實來源並修訂成果後，勾選完成標記。您可隨時匯出 JSON 學習紀錄或 Markdown 品牌提案大綱，在任何裝置接續工作。
          

        

      


      
      

        

          
學習紀錄與跨裝置備份管理

          
支援匯出完整 JSON 備份檔、全案 Markdown 提案簡報，或還原既有進度。

        

        

          
          
          
          
          
        

      


      
      

        

          
            這是已串接 AI、RAG 或 Firebase 的平台嗎？
            ▼
          
          

            本平台已整合 Firebase 雲端即時同步備份機制，自動保存您的品牌實作筆記與單元進度；同時也可隨時匯出 JSON 與 Markdown 檔案離線留存。RAG 單元提供完整架構設計、操作引導與 10 題評測流程，實際檢索系統與 AI 推論請依您採用的 AI 平台執行。
          

        


        

          
            下載的 Skill ZIP 包含哪些檔案？如何更新？
            ▼
          
          

            本單檔 HTML 已將五組原創 Skill ZIP 以 Base64 內嵌封裝，點擊「下載 Skill」即可直接存檔，不依賴外部伺服器資料夾。解壓縮後內含 SKILL.md、agents/openai.yaml、references/practice.md 與 references/brand-contract.md。
          

        


        

          
            如何評估每個單元的完成品質？
            ▼
          
          

            每項產出皆以「來源可追溯」、「品牌適配」、「交付完整」、「驗證可執行」四個面向進行檢查。完成標記為學員自我檢核紀錄，不代表講師認證或商業成效保證。
